# ADR-004 — Dist: publish target, curated sets, field selection, transform pipeline (v0.1 era)

**Date**: 2026-03-22
**Status**: Superseded by ADR-005 (v0.2 schema and per-package output shape)

> This ADR describes decisions made for the v0.1 catalog format and the original
> `build_dist.py` pipeline. The v0.2 redesign (ADR-005) changed the primary artifact
> from a merged set file to a per-package catalog file, and introduced a new set
> format. The publish target, curated-set membership, and pipeline split between
> collection and transform remain valid; the output shape and field mapping do not.

---

## Context

The private `catalog` repo holds raw Shape B activity catalogs under
`data/sources/nuget/pkg/{id}/{version}.json` — one file per `(packageId, version)` pair,
containing full assembly-level metadata: type members, localization strings,
ActivitiesMetadata keys, and developer-facing fields not intended for consumers.

A public **dist** is derived from this raw data: a curated, slimmed artifact that
conforms to `schemas/v0.1/activity-catalog.schema.json` and can be consumed by
LLMs and humans without access to the private repo.

---

## Decision

### Publish target

`catalog` remains private. Dist artifacts are published to `uips-fixtures.github.io`
(public, wired to GitHub Pages). The transform writes into a local checkout of that
repo and commits.

```
catalog/                          ← private, raw data
uips-fixtures.github.io/
  src/
    catalog/
      v0.1/
        {set-name}/
          activities.json
          index.json
```

URL pattern: `https://uips-fixtures.github.io/catalog/v0.1/{set-name}/activities.json`

### Curated sets

Set membership is declared in `catalog/config/curated.yaml`. A package may appear
in multiple sets. Version selection for all sets: **latest stable** — the highest
non-prerelease version present in `data/sources/nuget/pkg/` (versions containing
`-preview`, `-beta`, `-rc`, etc. are excluded).

**Set: `reframework-stable`** — packages used by the UiPath REFramework template,
derived from `rpapub/DriftingGears` `data/reframework_catalog.json`:

- UiPath.Excel.Activities
- UiPath.System.Activities
- UiPath.Testing.Activities
- UiPath.UIAutomation.Activities

**Set: `watchful-anvil`** — Watchful Anvil starter set:

- UiPath.Excel.Activities
- UiPath.FTP.Activities
- UiPath.PDF.Activities
- UiPath.System.Activities

### Field selection

Internal keys, raw localization tokens, and developer-facing metadata are stripped.
Only consumer-useful fields are emitted.

**Per activity** (source: `items[]` in Shape B):

| Kept as | Source field | Dropped |
|---|---|---|
| `fullName` | `fullName` | `displayNameKey` |
| `displayName` | `displayName` | `descriptionKey` |
| `description` | `description` | `categoryKey` |
| `category` | `category` | `iconKey` |
| `source.id` | `packageId` | `viewModelType` |
| `source.version` | `packageVersion` | `defaultFactory` |
| | | `displayNameAliases` |
| | | `shortName` |
| | | `mandatoryParentActivityFullName` |
| | | `propertyCount` |

**Per member** (source: `items[].properties[]`; entries with `browsable == false` are dropped):

| Keep | Drop |
|---|---|
| `name` | `declaringType` |
| `displayName` | `declaringAssembly` |
| `dataType` | `isInherited` |
| `memberKind` | `displayNameSource` |
| `argumentDirection` | `typeConverter` |
| `isRequiredArgument` | `editor` |
| `description` | |
| `category` | |

Locale: English only (`en` strings resolved at transform time).

### Output shape per set

```
src/catalog/v0.1/{set-name}/
  index.json        — source list: id, version, activityCount
  activities.json   — all activities in the set, conforming to activity-catalog.schema.json v0.1
```

### Pipeline

**Collection** (`collect-nuspec.yml`, nightly):
- Downloads nupkgs, invokes `Build-PackageCatalog.ps1` hook
- Writes raw Shape B to `data/sources/nuget/pkg/{id}/{version}.json`
- Skips pairs where both nuspec/manifest and catalog output already exist
- Trigger: schedule or `workflow_dispatch` (with optional `FORCE=true`)

**Transform** (`build-dist.py`, separate):
- Reads raw Shape B from `data/sources/nuget/pkg/`
- Reads `config/curated.yaml` for set definitions
- Applies latest-stable selection, field filtering, and browsable pruning
- Writes dist JSON into a checkout of `uips-fixtures.github.io`
- Re-run whenever transform logic or `curated.yaml` changes; raw data need not be re-collected

Raw data lives in `catalog` (private); derived dist lives in `uips-fixtures.github.io`
(public). The two repos are independently versioned and independently triggerable.

---

## Consequences

- Adding a package to a set: edit `curated.yaml`, re-run `build-dist.py`. No re-collection
  needed if the Shape B file already exists.
- Adding a package not yet collected: run `collect_nuspec.py` (`PACKAGES=<id>`) first,
  then `build-dist.py`.
- The `reframework` set is manually curated here; it does not dynamically re-read the
  DriftingGears catalog at transform time.
